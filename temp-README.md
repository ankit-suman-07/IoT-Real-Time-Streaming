# Real-Time Bike Rental Prediction — Apache Kafka Streams
### ENGR 5785G — Assignment 1

A real-time streaming pipeline that reads bike sharing sensor data row by row, streams it through Apache Kafka, runs a Random Forest ML prediction on each record using Kafka Streams, and displays live results on a web dashboard.

---

## What This Project Does

```
hour.csv (dataset)
      ↓
  Producer          → sends 1 row/second to Kafka topic: raw-data
      ↓
Streams Processor   → reads raw-data, calls ML model, writes to topic: predictions
      ↓
Output Consumer     → reads predictions, prints to terminal
      ↓
UI Dashboard        → live chart + table at http://localhost:5002
```

---

## Tech Stack

| Component | Technology |
|---|---|
| Message broker | Apache Kafka 3.6 (via Docker) |
| Stream processing | Java + Kafka Streams |
| ML model | Python — Random Forest Regressor (scikit-learn) |
| Model serving | Python — Flask REST API |
| Live dashboard | Python — Flask + Socket.IO + Chart.js |
| Infrastructure | Docker + Docker Compose |

---

## Dataset

**UCI Bike Sharing Dataset** — `hour.csv`
- Source: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- Task: Predict hourly bike rental count (`cnt`) from weather and time features
- Features used: `season, hr, holiday, weekday, workingday, weathersit, temp, atemp, hum, windspeed`

## Model Performance

| Metric | Score |
|---|---|
| Algorithm | Random Forest Regressor (100 trees) |
| MAE | ~33.21 |
| R² Score | ~0.89 |

```
abc123         confluentinc/cp-kafka:7.5.0      Up 30 seconds
def456         confluentinc/cp-zookeeper:7.5.0  Up 31 seconds
```

---

### Step 6 — Create Kafka topics

> Only needs to be done once. Skip if topics already exist.

First get your Kafka container name:
```bash
docker ps
```

Then create both topics (replace `kafka-local-kafka-1` with your actual container name):

**Windows / Mac / Linux:**
```bash
docker exec -it kafka-local-kafka-1 kafka-topics \
  --create --topic raw-data \
  --bootstrap-server localhost:9092 \
  --partitions 1 --replication-factor 1

docker exec -it kafka-local-kafka-1 kafka-topics \
  --create --topic predictions \
  --bootstrap-server localhost:9092 \
  --partitions 1 --replication-factor 1
```

Verify topics exist:
```bash
docker exec -it kafka-local-kafka-1 kafka-topics \
  --list --bootstrap-server localhost:9092
```

Expected output:
```
predictions
raw-data
```

## Windows Only — Automated Start/Stop

Instead of opening 5 terminals manually, use the provided batch scripts.

> **Requirement:** Kafka must be running via `docker-compose up -d` before running `start.bat`

**Start everything:**
```
Double-click start.bat
```
This opens all terminals automatically in the correct order and launches the browser.

**Stop everything:**
```
Double-click stop.bat
```
This shuts down all terminals, stops all Python and Java processes, and brings down the Kafka Docker containers.

## Troubleshooting

**`mvn` not recognized**
→ Maven is not in your PATH. Follow Step 3 in Prerequisites above.

**`docker ps` shows no containers**
→ Docker Desktop is not running. Open Docker Desktop and wait for it to fully load, then try again.

**Port 9092 already in use**
→ Another Kafka instance is running. Run `docker-compose down` in the kafka-local folder first.

**Model server returns errors**
→ Make sure `model/bike_model.pkl` exists. If not, run `train_model.py` again.

**UI not updating**
→ Make sure the Producer is running and the Streams Processor has started successfully before the Producer.

**Windows: `-Dexec.mainClass` not recognized**
→ Wrap the argument in quotes: `"-Dexec.mainClass=com.assignment.Producer"`
